# 糖尿病配餐与血糖管理工作台（本地版）

给营养师用的本地配餐工具：**输入基础数据 → 自动生成符合配餐基本要求的交换份食谱（显示营养素与 GI/GL，食材可平替）**；
**输入实时血糖与运动情况 → 自动重算进餐时间、进餐量、食物种类与运动处方**。

全部在本机运行，**不联网、不上传数据**，数据只保存在浏览器 localStorage 里。

## 在线使用

- **GitHub Pages**：<https://gusihangluta.github.io/diabetes-nutrition-workbench/>
- **离线下载**：<https://github.com/GUSIHANGLUTA/diabetes-nutrition-workbench/releases/latest>

在线版与离线单文件版功能一致；在线版首次加载后也可以断网使用。

## 二、快速开始

1. 双击 `糖尿病配餐与血糖管理.html`（Chrome / Edge 均可）。
2. 想先看效果：点右上角 **载入示例**（会填入一位示例患者、生成配餐、并跑一遍血糖联动与 CGM 分析）。
   > 界面预览见 `docs/` 目录：`截图1-基础数据与能量处方.png`、`截图2-配餐模板与营养.png`、`截图3-血糖联动.png`、`截图4-食材平替.png`。
3. 日常流程：
   - **① 基础数据与能量处方**：填性别、年龄、身高、体重、活动强度、糖尿病类型、治疗方式、肾功能、合并症、营养目标 → 自动算出理想体重、BMI、体型、每日能量与三大营养素目标（可手工微调）。
   - **② 配餐模板（交换份）**：选餐次分配方案与模板口味 → 生成一日食谱（每餐、每种食物的交换份、可食部克数、家常计量、能量、蛋白、脂肪、碳水、纤维、GI、GL），并给出全天营养对比与「配餐基本要求自检」。表格里每一行都有 **替换** 按钮，可当场平替。
   - **③ 食材平替**：选一个食材，按 **碳水等价 / 能量等价 / 蛋白质等价** 找平替，可限制「同类食物」与「GI 不高于原食材」，并显示替换前后的营养素、GI、GL 差值。也可以把食物库导出成 JSON，用 Excel 改完再导入。
   - **④ 血糖 · 运动联动**：填当前血糖、趋势箭头、测量时段、距上一餐时间、症状、酮体、下一步计划与运动强度时长 → 输出**即时处理、进餐时间、主食量与种类调整、加餐建议、运动处方、复测计划、就医预警**，并给出当日时间轴与「调整后的配餐」。再往下可以粘贴/导入 CGM 读数，得到 TIR/TAR/TBR、GMI、CV 与血糖曲线。
   - **⑤ 数据与设置**：食物库导入导出、本机存档管理、血糖判定阈值自定义。

**打印 / 导出 PDF**：点右上角「打印 / 导出 PDF」，打印样式会自动隐藏按钮与选项卡，五个模块按 A4 分页。

## 三、配餐规则与依据（模块①②）

| 项目 | 规则 |
| --- | --- |
| 理想体重 | 身高(cm) − 105（Broca 改良公式） |
| 体型 | BMI <18.5 消瘦；18.5～23.9 正常；24～27.9 超重；≥28 肥胖（中国标准） |
| 能量系数 | kcal/kg 理想体重：消瘦 25/35/40/45；正常 20/30/35/40；超重肥胖 15/22/30/35（对应卧床/轻/中/重体力） |
| 调整项 | 妊娠中晚期 +300、哺乳 +500、减重 −450、增重 +300、≥65 岁取下限、最低 1000 kcal |
| 三大营养素 | 碳水 45%～60%（默认 50%，并按脂肪 20%～30% 自动协调）；蛋白 1.0～1.3 g/kg（CKD 3 期 0.8～1.0、CKD 4～5 期 0.6～0.8，妊娠/1 型 1.1～1.5，老年 ≥1.2，减重 1.2～1.5），并按能量的 15%～25% 校正；脂肪为剩余供能比并夹在 15%～40% |
| 膳食纤维 | 14 g/1000 kcal（约 25～30 g/d） |
| 交换份 | 1 交换份 = 90 kcal，按「食物交换份法」把总能量换算成各餐各类食物的份数 |
| 交换份分配 | 蔬菜 1～2.5 份、水果 1～1.5 份、乳类 1.5～2.5 份、豆制品 0.5～1.5 份、坚果 0.5～1 份、烹调油 1.5～3 份（15～30 g）；谷薯补足碳水目标、肉蛋鱼虾补足蛋白目标（定点迭代 + 按实际食材回算校准，能量偏差一般 ≤5%） |
| 餐次分配 | 标准三餐（1/5·2/5·2/5）、三餐+2 加餐（20/5/30/5/30/10）、少食多餐 6 餐、胃轻瘫/餐后高血糖 7 餐，可自定义各餐百分比 |
| 食材选择 | 主食强制搭配 ≥1/3 全谷杂豆（早餐优先燕麦/玉米/薯类）；蔬菜优先深色蔬菜与菌藻（≥50%）且优先高纤维品种；蛋白优先鱼虾、禽肉、蛋、豆制品；全天鸡蛋 ≤1 个并设胆固醇预算；高尿酸自动排除动物内脏等高嘌呤食物；CKD 4～5 期自动排除高钾磷食物；超重/肥胖与血脂异常自动优选低脂乳制品与低脂豆制品 |
| 自检 | 16 项「配餐基本要求」自查：能量（成分表口径与 4/4/9 口径双看）、碳水/蛋白/脂肪供能比、蛋白质、膳食纤维、胆固醇、钠、蔬菜量、深色蔬菜与菌藻占比、全谷杂豆占主食比例、烹调油、水果、乳类、平均 GI、单餐 GL、全天 GL、以及合并症专项 |

**GI / GL**：GI 取自《中国食物成分表》血糖生成指数附表；GL = GI × 可利用碳水(g) / 100。单餐 GL 理想 ≤25、全天 GL 理想 ≤80、平均 GI ≤55（低 GI 膳食）。GI 附表中文字带 `≈` 者表示该食物未被附表直接收录、按同类食物或文献常用值估算；膳食纤维标 `≈` 者同理（原表该项缺失）。

## 四、血糖 · 运动联动规则（模块④）

输入：当前血糖、CGM 趋势箭头、测量时段、距上一餐时间、症状、酮体、下一步计划、计划运动强度与时长。

| 血糖（mmol/L） | 处理 |
| --- | --- |
| <3.0（严重低血糖） | 立即 15～20 g 快速碳水，15 分钟复测，未达标重复；意识障碍禁止喂食、立即急救；禁止运动 |
| 3.0～3.9 | 立即 15 g 快速碳水（葡萄糖片/果汁/方糖），15 分钟复测 ≥3.9 再进餐；禁止运动；用胰岛素/促泌剂者提醒 24 小时内易再发 |
| 3.9～5.6 | 主食不减量、立即进餐（不要为等血糖升高而推迟）；若要运动，先加餐约 20 g 碳水并复测 ≥5.6 |
| 5.6～7.8 | 按计划进餐与运动（餐后 45～90 分钟开始中等强度有氧） |
| 7.8～10.0 | 主食 −10%，优选低 GI；餐后 45～60 分钟运动 25～45 分钟；餐后 2 h 复测 |
| 10.0～13.9 | 主食 −20%～30%，增加非淀粉类蔬菜与优质蛋白；餐前可先做 10～15 分钟低强度活动再进餐；运动降为中等强度 20～40 分钟；1～2 h 复测 |
| >13.9 | 主食 −30%～40%；**暂缓运动**、查酮体、补水、按医嘱处理；酮体阳性立即就医（警惕 DKA） |

趋势修正：↑↑/↑ 且血糖偏高时主食再 −10%；↓/↓↓ 时主食不减并在 30～60 分钟内复测；睡前 <6.7～7.0 建议加餐 15～20 g 慢吸收碳水；较长/较大强度运动后 12～24 小时存在延迟性低血糖风险，建议夜间加测。

运动处方同时给出：能否运动及禁忌、餐后开始时间、强度形式（自感用力/心率区间描述）、时长、每周总量（≥150 分钟中等强度有氧 + 每周 2～3 次抗阻）、运动前中后监测点、随身携带糖果与身份卡等注意事项。

**「调整后的当日配餐」**会把上述结论落到具体食物：主食按系数改克数、高 GI 主食自动换成低 GI 品种（等交换份），并重新计算该餐碳水量；使用胰岛素/促泌剂者会提示与药量匹配需遵医嘱。

## 五、数据来源与准确性

1. **食物营养成分**：《中国食物成分表（标准版 第6版）》「能量和食物一般营养成分」表格整理数据
   （开源整理项目 [Sanotsu/china-food-composition-data](https://github.com/Sanotsu/china-food-composition-data)，
   本工具从中挑选糖尿病配餐常用食物 **137 条**）。
2. **GI 值**：同上仓库收录的《中国食物成分表》**食物血糖生成指数（GI）附表**（259 条，已内置为查询参考表）。
3. **缺失值处理**：原表膳食纤维/部分项目为「—」时，不当作 0，而是按同表同族条目或常用值给出估算值并在界面标 `≈`；纯油脂与乳类确实不含膳食纤维，取 0。
4. **能量口径**：成分表「能量」按 Atwater 系数并计入膳食纤维等计算，与 4/4/9 折算值通常相差 3%～5%，界面上两个口径都显示，供能比以 4/4/9 口径为分母。

> 建议：正式使用前，用你所在机构的《中国食物成分表》版本核对食物库（⑤ 数据与设置 → 导出食物库 JSON → Excel 修改 → 导入），
> 并把本机构常用的地方食材、品牌食品补进去。食物库支持任意扩充，导入后自动同步到配餐、平替与查询。

## 六、维护与二次开发

```powershell
# 1) 修改食物库：编辑 tools/build_food_db.py 里的食物清单（可增删改），再重新生成
python tools/build_food_db.py

# 2) 引擎自测（Node.js）
node tools/test_engines.js      # 处方/配餐/平替/血糖/CGM 单元自测
node tools/matrix.js            # 8 类患者 × 4 种餐次方案 × 3 种口味 = 96 组合的达标矩阵
node tools/debug_plan.js three_snack cn   # 打印某方案的一日食谱，人工核对

# 3) 界面自检（浏览器）：打开 app/index.html#selftest，页面顶部会显示自检结果；
#    #demo 载入示例数据，#demo,tab-glucose 直接定位到某个选项卡。

# 4) 重新打包单文件版
python tools/build_single.py
```

结构说明：`data-foods.js`（数据）→ `engine-prescription.js`（配餐引擎，纯函数）→ `engine-glucose.js`（血糖规则引擎与 CGM 统计，纯函数）→ `app.js`（界面绑定与渲染）。
两个引擎不依赖 DOM，可直接被 Node 脚本或将来接入的其他前端复用。所有血糖判定阈值集中在 `GlucoseEngine.DEFAULT_RULES`，可在界面 ⑤ 修改并存到本机。

## 七、免责声明与局限

- 本工具是**营养师配餐计算与患者教育辅助工具**，不构成诊疗意见，不能替代医师处方与营养师面诊；用药调整必须由医师决定。
- 出现血糖 <3.0 或 >13.9 mmol/L、酮体阳性、意识改变、呕吐腹痛等情况，请立即按机构流程处理并联系医生。
- 食物库为常用食物子集（137 条），地方食材与加工食品需自行补充；GI 值多来自 2002 版附表，个体血糖反应存在差异，建议结合血糖仪或 CGM 实测个体反应。
- 目前未内置：食物–胰岛素剂量换算（碳系数/胰岛素敏感系数）、食谱成本与采购清单、多日食谱轮换与营养素（维生素/矿物质）全量核算。这些可以作为下一版扩展。
